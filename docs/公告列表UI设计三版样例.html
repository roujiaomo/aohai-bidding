三个方案共同修复的问题

  • 徽章不再重叠：优先级只出现一次，类别标签降级为辅助信息（灰底小胶囊或文字），与优先级分离摆放。
  • 关键词统一样式：去掉"关键词"纯文本前缀，标签全部同款胶囊/文字分隔，一组一个样式。
  • 金额要点降噪：绿底白字改为浅绿底+绿字（方案 B 改为圆点+文字），保留醒目但不刺眼。
  • 长标题治理：方案 A 允许两行自然折行；方案 C 单行省略号；行高、留白统一节奏。
  • 颜色收敛：全页只保留红（重点）/橙（跟进）/蓝（一般）/绿（金额）四个语义色，表头改浅灰不再抢戏。
  • 数字等宽：日期与金额使用等宽数字（tabular-nums），列对齐整齐。

怎么选

  • 方案 A：改动最小、最接近现在的表格形态，稳妥之选。
  • 方案 B：视觉最舒服、分组最清晰，但单屏显示条数最少。
  • 方案 C：扫读效率最高、一屏看最多，适合数据量上来以后（现在已 260+ 条且持续增长）。
