- 项目：遨海商机雷达（app/radar.py）

## 一、本地单元测试用例（34 项）

### 1. 评分管线（6 项）

| 编号 | 用例 | 输入 | 预期结果 |
|---|---|---|---|
| 1.1 | 0 分门槛 | 标题/正文不含任何业务关键词的公告 | 得分 0，不入库 |
| 1.2 | 分类得分公式 | 某分类命中 1/2/3 个关键词 | 得分分别为 15/22/29，且不超过该分类权重 |
| 1.3 | 权重上限 | 命中词数很多、权重设 30 的分类 | 该分类得分封顶 30 |
| 1.4 | 区域加分 | region 命中一级重点区域 / 二级重点区域 | 分别 +15 / +8，取高不叠加 |
| 1.5 | 采购方加分 | buyer 命中 1~2 个采购方关键词 | +12，公式 min(20, 8+4×n) |
| 1.6 | 预算加分与封顶 | budget ≥ 50 万；多分类全命中 | +8；总分封顶 100 |

### 2. 入库噪声闸（6 项）

| 编号 | 用例 | 输入标题示例 | 预期结果 |
|---|---|---|---|
| 2.1 | 招采特征词放行 | "…航道整治工程公开招标公告" | 放行 |
| 2.2 | 新闻噪声拒收 | "…救助工作通知"（正文含业务词） | 拒收 |
| 2.3 | 裸机构名拒收 | "中华人民共和国交通运输部" | 拒收 |
| 2.4 | 截断标题放行 | "…监理二标（" 尾带 …/... | 放行 |
| 2.5 | 项目结构词放行 | "…航道测量项目"（无"公告"字样） | 放行 |
| 2.6 | 兜底标题命中 | 无特征词无结构词，业务关键词命中标题本身 | 放行；仅正文命中则拒收 |

### 3. 商机分类打标（3 项）

| 编号 | 用例 | 预期结果 |
|---|---|---|
| 3.1 | 三类分类 | 标题按"前期线索/直接产品/集成项目"配置顺序匹配，先命中者生效 |
| 3.2 | 空标题 | 返回空，不打标 |
| 3.3 | 匹配顺序 | 多分类同时可命中时，配置靠前的分类生效 |

### 4. 商机级别阈值（2 项）

| 编号 | 用例 | 预期结果 |
|---|---|---|
| 4.1 | 默认阈值 | ≥80 重点关注、≥50 值得跟进、其余一般关注 |
| 4.2 | 自定义阈值 | 修改 opportunity_levels 后优先级映射随之变化 |

### 5. 标题相似度（3 项）

| 编号 | 用例 | 预期结果 |
|---|---|---|
| 5.1 | 数字语义校验 | "监理一标" ≠ "监理二标"，"第二次" ≠ "第三次" |
| 5.2 | 尾缀变体 | 公告类型词后拼接"【电子标】""-项目名"等尾巴识别为同一公告 |
| 5.3 | 截断前缀 | 短标题（≥12字）是长标题前缀 → 同一公告 |

### 6. 去重合并（2 项）

| 编号 | 用例 | 预期结果 |
|---|---|---|
| 6.1 | 跨地区同标题合并 | 归一化标题完全一致但地区写法不同 → 判定同一公告并合并 |
| 6.2 | 跨站来源码累加 | 合并后 source_code 为逗号串（如 tianyancha,ccgp_search） |

### 7. 入库链路（7 项）

| 编号 | 用例 | 预期结果 |
|---|---|---|
| 7.1 | 重抓保护人工字段 | 同指纹重抓不覆盖优先级/备注/跟进状态 |
| 7.2 | 官方源覆盖天眼查 | 官方与聚合源合并时标题/链接/正文无条件取官方 |
| 7.3 | 天眼查不覆盖官方 | 反向（已有官方再来天眼查）保留官方内容 |
| 7.4 | 软删拦截 | 已标记无用的记录，同指纹或近似标题重抓不再入库 |
| 7.5 | 噪声闸入库层拒收 | 高分新闻公告在 upsert_tender 被拒，返回 (False, 0) |
| 7.6 | 缺字段校验 | 缺 title/source_url/source_code 抛错 |
| 7.7 | 未知来源校验 | source_code 不在 sources 表抛错 |

### 8. 规则校验（5 项）

| 编号 | 用例 | 预期结果 |
|---|---|---|
| 8.1 | 阈值倒挂 | key_threshold < follow_threshold 被拒 |
| 8.2 | 空关键词 | 分类关键词为空被拒 |
| 8.3 | 权重越界 | 权重不在 1-100 被拒 |
| 8.4 | 分类重名 | 两个同名分类被拒 |
| 8.5 | 合法规则 | 保存成功且读回一致 |

## 五、去重兜底专项用例（测试中发现并新增）

| 编号 | 用例 | 预期 |
|---|---|---|
| D-1 | 精确同标题重复对 | 合并进最早记录，来源码/正文取优 |
| D-2 | 同项目不同阶段公告（招标/中标） | **不得合并** |
| D-3 | 同项目不同阶段公告（比选/比选结果） | **不得合并** |
| D-4 | 同项目不同阶段公告（招标/废标） | **不得合并** |
| D-5 | 截断标题（尾带 …） | 不参与模糊合并，仅精确同标题可合并 |
| D-6 | 公告阶段分类器 | "…招标公告废标公告"阶段取最后出现的"废标"；正则长词优先（"中标公告"不拆成"公告"） |
