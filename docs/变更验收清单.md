# 遨海商机雷达｜变更验收清单

每次功能交付由开发方完成本清单；业务方只需确认业务目标、不可变化的规则和正反样例。

仅应用与当前变更有关的项目；只读审查、解释和 Git 同步不套用。低风险样式或文案采用针对性检查，规则变化仍执行完整门禁。已有明确授权不重复确认；目标、范围扩大或平台强制审批除外。

## 交付前

- [ ] Agent 已自行运行变更影响检查，并同步规则文件 A（若涉及规则行为）。
- [ ] 按影响范围验证正常和边界/失败路径；规则变化补充固定回归，已有充分覆盖不重复新增。
- [ ] 运行一次 `release-gate`（包含规则文档校验）；同一代码、配置和环境状态复用结果。
- [ ] 已判断历史数据处置；需要写入时先备份和只读预览，且写入范围须有明确授权。
- [ ] 已记录适用的备份路径、Git 基线和回退方法，不要求为未发布的本地修改创建标签。

## 验收项

- [ ] 抓取返回数、入库数、去重数和硬排除数可追溯。
- [ ] AI 结论可回溯到原文事实；模型失败不进入商机页。
- [ ] 实时、历史、回收站、AI 页与钉钉推送符合规则文件 A。
- [ ] 质量报告没有确定性污染、来源失败或 AI 展示不一致告警。

## 交付说明模板

`目标`、`未改变项`、`规则影响`、`历史数据影响`、`未来数据影响`、`验证结果`、`回退点`、`观察项`。

功能或规则修改的实际交付单列“自测结果”和“历史数据处置”；纯样式、文案可简写。检查器误报时可使用差异绑定复核报告，格式与留档要求见 `docs/通用Agent指令优化方案.md`；真实规则变化不得以该报告代替同步规则文件和回归样本。
